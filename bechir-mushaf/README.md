# مصحف بشير | BECHIR MUSHAF

## المواصفات المعتمدة
- مصحف ملون بأحكام التجويد برواية حفص عن عاصم.
- صفحات مصحف ورقي أصلي مزخرف، مع الحفاظ على ترتيب 604 صفحات.
- القراءة دون إنترنت: تضمين صفحات أصلية موثوقة ومصرح باستخدامها داخل حزمة التطبيق.
- التلاوات عبر الإنترنت لعدة قراء، مع تنزيل السور للاستماع دون اتصال لاحقًا.
- عرض صفحة المصحف بأقصى مساحة ممكنة، بين شريط علوي صغير وشريط سفلي صغير.
- الشريط العلوي: اسم السورة ورقم الصفحة والفهرس.
- الشريط السفلي: اختيار القارئ، تشغيل/إيقاف، علامة مرجعية.
- إخفاء الشريطين بلمسة واحدة؛ عدم قص الآيات أو زخارف الصفحة.
- فهرس السور والأجزاء، العلامات المرجعية، حفظ آخر صفحة، تكبير الصفحة.
- أيقونة من الهوية الموحدة لتطبيقات BECHIR، وAPK بعد اكتمال التطبيق واختباره.

## شرط النشر
لا تُضاف صور صفحات القرآن أو التلاوات إلى التطبيق إلا بعد التحقق من سلامة المحتوى، دقة الرواية والتجويد، وحقوق إعادة التوزيع. لا تستخدم صور مولّدة للآيات.

## حالة العمل
وثيقة مواصفات أولية فقط؛ التطبيق وAPK لم يُبنَيا بعد.
